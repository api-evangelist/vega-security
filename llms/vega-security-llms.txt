# Vega Security

> Vega (vega.io) is an AI-native security operations platform — "The Operating System for Agentic SecOps." Its Security Analytics Mesh (SAM) federates queries across every security data source in place (no ingestion, migration, or egress) and powers agentic detection engineering, autonomous alert triage, and security analytics, with detection coverage continuously assessed against MITRE ATT&CK. Backed by Accel.

Vega positions itself as a post-SIEM platform: AI-powered detections, agentic triage of every alert, federated query-at-source analytics, IR readiness/coverage assessment, and legacy SIEM cost reduction. The product application (app.vega.io) and product documentation (docs.vega.io, Mintlify) are login-gated; no public API reference, OpenAPI, or package registry SDKs were found as of 2026-07-21.
