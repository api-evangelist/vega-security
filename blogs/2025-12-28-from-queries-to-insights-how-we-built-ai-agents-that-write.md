TL;DR Query languages like KQL excel at fetching data, but analyzing results - finding patterns, running statistics, exploring iteratively - remains manual work. In this post, we share how we built a code execution sandbox that enables AI agents to analyze logs in real-time by dynamically generating and executing Python code. This capability powers multiple features across our platform, from automated data source mapping to intelligent query summaries and AI-assisted triage.
